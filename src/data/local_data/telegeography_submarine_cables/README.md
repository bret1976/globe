# TeleGeography Submarine Cable Map

Bundled GeoJSON for international submarine cable systems and landing points,
mirrored from [bilawalsidhu/gods-eye-view](https://github.com/bilawalsidhu/gods-eye-view)
(`src/data/local_data/telegeography_submarine_cables/`), originally from
TeleGeography's [Submarine Cable Map](https://www.submarinecablemap.com/).
