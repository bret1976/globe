        Public API

        Read-only · no key

        Plain GET, JSON unless noted, CORS open. Data keeps its source licence (AISStream terms; adsb.lol ODbL 1.0; GPSJam). Please poll no faster than every 30 s.

        GET /api/blackout/v1/health · /watch/health
        Feed, detector and storage status. 503 when nothing is live.
        GET /api/blackout/v1/dark
        kind=all|ships|aircraft · window=live|24h · format=json|csv|geojson
        GET /api/blackout/v1/aircraft
        Military-aircraft went-dark detector (worldwide, server-side).
        GET /api/blackout/v1/regions
        Latest GNSS-integrity read for each watch region.
        GET /api/gnss-integrity/history
        24 h of five-minute NIC/NACp frames; ?at=<ms> for one frame.
        GET /api/gpsjam/dates
        Daily GPSJam files; /api/gpsjam?date=YYYY-MM-DD for one day.

        Deep links: this page keeps its state in the address — #t=2026-10-24 (day) or #t=<ms> (GNSS frame), &region=baltic, &target=ship:<mmsi>. Copy the address bar to share a view.
